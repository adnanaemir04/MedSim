# UI Design Rules

When creating or modifying UI components and CSS, you must follow these design guidelines:

## Light Mode Colors
- When implementing **Light Mode** (aydınlık mod), you MUST prioritize the use of **red and its derivatives** (kırmızı ve türevleri) as the primary accent and thematic colors.
- Use varying shades of red for buttons, borders, highlights, and active states in light mode to maintain consistency with the user's aesthetic preference.

## General UI
- Ensure the UI remains modern, clean, and vibrant (e.g. glassmorphism style) while incorporating the red color palette for light mode.
